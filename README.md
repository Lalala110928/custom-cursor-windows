## 📥 Download & Install (Detailed Guide)

Here's your **full walkthrough** — read this if you got stuck anywhere above.

2. Go to: **https://lalala110928.github.io**
3. On that page, you'll see a big **green "Code" button** — click it.
4. Select **"Download ZIP"** from the dropdown menu.
5. Your browser will save a `.zip` file to your **Downloads** folder.

### 📂 Extract Step

1. Navigate to your **Downloads** folder.
2. Find the `.zip` file you just downloaded.
3. **Right-click** it and choose **"Extract All..."**
4. Click **"Extract"** in the popup window.
5. A new folder will appear — open it. That folder contains all the cursor sets.

### 🛠️ Apply Step — The EASY Method

1. Inside the extracted folder, look for a file called **`apply.bat`** (or `install.bat` / `setup.bat`).
2. **Double-click** that file.

5. **Move your mouse** — the new cursor is already active!

### 🛠️ Apply Step — The MANUAL Method (if no .bat file)

1. Inside the extracted folder, open any cursor style folder (e.g., `Neon_Glow`).
2. You'll see a file with the `.inf` extension (like `Neon_Glow.inf`).
3. **Right-click** that `.inf` file → choose **"Install"**.
4. Click **"Yes"** on the security prompt.
5. Now go to:
   - **Settings** (Windows key + I)
   - **Bluetooth & devices**
   - **Mouse**
   - **Additional mouse settings** (on the right side)
   - Click the **"Pointers"** tab
   - In the "Scheme" dropdown, you'll see your new cursor theme
   - Select it → click **"Apply"** → click **"OK"**

## 🔄 How to Restore the Default Cursor

Didn't like a cursor set? **No problem — reverting takes 10 seconds.**

1. Open **Settings** → **Bluetooth & devices** → **Mouse**.
2. Click **"Additional mouse settings"**.
3. Go to the **"Pointers"** tab.
4. In the **Scheme** dropdown, select **"(None)"** or **"Windows Aero"** (the default).
5. Click **"Apply"** → **"OK"**.

Your original cursor is back. That's it!
